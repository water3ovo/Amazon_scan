# V1 -> V2 迁移说明

V1 的主要问题：
- 自带约 390MB Chrome/ChromeDriver，压缩包约 182MB。
- Windows 路径写死为 `D:/python/...`。
- `finish.py` 近 100KB，混杂多站点历史 selector、Excel 写入、截图、页面解析和业务逻辑。
- 每个 ASIN 截图并嵌 Excel。
- 第一条商品固定等待 30 秒，并残留墨西哥邮编提示。
- 抓取大量当前流程不用的字段（RAM、容量、屏幕、视频、Bullet Points、安全资源等）。
- 抓取失败值与真实业务状态混在同一列，存在“爬虫没抓到 = 缺货”的误判风险。

V2 的变化：
- 删除内置 Chrome / ChromeDriver，Selenium Manager 自动管理 Driver。
- 所有路径相对项目目录。
- AE/SA 独立持久 Profile，可一次配置配送地址。
- 业务异常与技术抓取状态拆分。
- 只保留当前扫查表需要的字段。
- Mapping/PSI/在投逻辑从爬虫中解耦，输入只是一张任务表。
- 本品按“在投状态”过滤；country+ASIN 去重。
- 只在失败/部分失败时截图。
